# Banned moves

Each ban carries its reason. Do not substitute a sibling of a banned move; the reason tells you what the sibling would also fail.

| Banned move | Reason |
| --- | --- |
| Agenda slide | Signals the hour is about you; open on their scenario instead |
| Company or customer-logo slide | Spends credibility you haven't earned yet |
| Tell-show-tell | Announces the trick before performing it |
| Feature-tour ordering | No decision moment, no hinge |
| "Imagine a world where..." | Abstraction where specificity is the whole play |
| ROI calculator or a savings percentage | A number they didn't produce, which they'll discount to zero |
| "Does that make sense?" | Asks for reassurance, not signal; use a probe beat |
| "Any questions?" ending | Hands control to the quietest person in the room |
| "Next steps" slide | A slide where an action should be |
| Happy-path-only admin scene | The off-switch is the confidence beat |
| Any question that waits for an answer | There is no discovery segment; discovery is by watching |
| Comparison slide against the incumbent | The alternative's gap is shown on their workflow, not asserted |
| Generic demo data (Acme, Jane Doe, #general) | The mirror tenant is the credibility play |
